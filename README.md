# 🛒 Olympus E-Commerce

Olympus is a full-stack e-commerce web application built with the MERN stack.  
The project was created to practice and implement a complete online shopping experience, including authentication, product management, shopping cart, wishlist, payments, reviews, and an administration system.

## 🛠️ Technologies

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- React Hook Form
- Framer Motion
- Lucide React
- Sonner
- Auth0
- Node.js
- Express.js
- MongoDB + Mongoose
- Stripe
- Resend

## ⚙️ The Process

I started the project by building the frontend structure with React, TypeScript and Vite. I then implemented the application's routing, reusable components and state management for features such as authentication, products, cart, wishlist and purchases.

After establishing the frontend, I developed the backend using Node.js, Express and MongoDB. The API handles products, users, purchases, reviews and other application data.

Once the main functionality was working, I integrated external services such as Auth0 for authentication, Stripe for payments and Resend for transactional emails.

Finally, I focused on improving the user experience by adding animations, notifications, validation, protected routes and an administration interface.
